# Фото автора

Чтобы фотография появилась в блоке «О проекте», положите файл сюда,
в папку `assets/`, с именем:

```
avatar.jpg
```

(либо `avatar.png` — сайт сначала попробует `.jpg`, если не найдёт — `.png`)

## Требования к фото

- Квадратное соотношение сторон (или близкое к нему) — обрежется по кругу
- Минимум 300×300 px, чтобы не размывалось на больших экранах
- Формат JPG или PNG

## Как добавить через Termux

Если фото уже лежит в загрузках телефона:

```bash
cp ~/storage/downloads/ваше_фото.jpg ~/kernel-site/assets/avatar.jpg
cd ~/kernel-site
git add assets/avatar.jpg
git commit -m "Добавлено фото автора"
git push origin main
```

Пока файла нет — на сайте автоматически показываются инициалы «ДЖ»
на цветном фоне вместо фото, ничего не сломается.
